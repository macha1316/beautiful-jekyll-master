# はじめに

Mac に移行した時に Windows コマンドと若干混同することがあったので、他にもそんな人がいるのでは？と思い記事にしました。超重要なコマンドを厳選しました！ぜひ知らないものがあったら覚えてみてください。

# コマンド一覧

```
コピー
command + C

ペースト
command + V

開いているファイル削除
command + W

ファイル移動
command + shift + ←→

行の先頭に移動
command + ←

1単語移動
option + ← / option + →

単語検索
command + F

行をまるごと選択
command + L

```
